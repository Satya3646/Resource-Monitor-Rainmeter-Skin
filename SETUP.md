Steps : 
1. Head over to [Rainmeter-Download](https://www.rainmeter.net/) and download rainmeter.
2. Run the .exe file downloaded to install Rainmeter.
3. After setting up Rainmeter download the .rmskin file includes in this repository.
4. Double Click on the downloaded .rmskin file to load the skin into rainmeter.
5. That's it the skin should now have loaded and visible on the screen.

---

There are a few things that must be done after installing the skin package.
Position the skin as need on the desktop and then open rainmeter.
Now toggle the position setting to "On Desktop" as shown in the image.
